# Software-generated examples

Open any scenario's `report.html` in a browser. `measurements.csv` contains final requested samples, and `run.json` preserves all acquisition attempts and configuration. `summary.json` compares the six runs.

These files were generated by:

```bash
python scripts/generate_examples.py
```

Rerunning the script replaces these example files. It does not write to or delete the live `outputs/runs.sqlite3` history. Sample measurements are deterministic for the same configuration, generator version, and seed; timestamps, run IDs, and execution times change.
